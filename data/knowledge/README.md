# NexusPulse Knowledge Base

This directory structure organizes different types of e-commerce data for the NexusPulse RAG (Retrieval-Augmented Generation) system.

## Directory Structure

### 1. brand_assets/
**Purpose:** For brand stories, tone of voice, logos, and other brand-related assets.

**Example files:**
- `brand_story.md`
- `tone_of_voice_guide.md`
- `logo_specifications.pdf`
- `brand_guidelines.md`

### 2. product_specs/
**Purpose:** For manuals, technical specs, competitor analysis, and product-related information.

**Example files:**
- `product_manual_v1.0.md`
- `technical_specs_electronic_device.md`
- `competitor_analysis_2026.md`
- `product_comparison_chart.md`

### 3. compliance_rules/
**Purpose:** For FDA/CE regulations, platform policies, and other compliance-related information.

**Example files:**
- `fda_2026_battery_regulations.md`
- `ce_mark_requirements.md`
- `amazon_selling_policies.md`
- `tiktok_compliance_guidelines.md`

### 4. marketing_sop/
**Purpose:** For viral scripts, influencer outreach templates, email campaigns, and other marketing-related standard operating procedures.

**Example files:**
- `viral_tiktok_script_template.md`
- `influencer_outreach_email.md`
- `social_media_content_calendar.md`
- `marketing_campaign_checklist.md`

### 5. financial_logic/
**Purpose:** For inventory calculation formulas, P&L rules, and other financial-related logic.

**Example files:**
- `inventory_calculation_formula.md`
- `profit_and_loss_rules.md`
- `pricing_strategy_guide.md`
- `financial_forecasting_model.md`

### 6. inbox/
**Purpose:** For raw, unprocessed files that need to be categorized and moved to the appropriate directory.

**Example files:**
- `new_product_specs_2026.pdf`
- `market_research_report_q1_2026.md`
- `competitor_analysis_draft.md`

## Note for Future AI Agents

When adding new knowledge to the NexusPulse system, always check which category fits best before storing the information. Proper categorization ensures efficient retrieval and generation of relevant insights for e-commerce decision-making.
