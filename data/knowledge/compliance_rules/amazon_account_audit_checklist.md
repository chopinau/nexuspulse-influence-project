# Amazon Compliance & Account Audit Checklist

**版本号**: 1.0
**适用范围**: 亚马逊全球开店 (Amazon Global Selling)
**合规等级**: 严格 (Strict/White-hat)
**描述**: 本文档涵盖 Listing 上架前的 52 点合规自查、账号身份验证材料标准及封号申诉逻辑框架。所有标准基于亚马逊官方服务条款 (TOS) 及公开政策。

## 1. Listing 上架前合规自查清单 (52-Point Checklist)

### 1.1 图片合规 (Image Compliance)
* [ ] **主图背景**: 必须为纯白色 (RGB 255, 255, 255)。
* [ ] **产品占比**: 产品必须占据图片区域的至少 85%。
* [ ] **真实性**: 图片必须展示客户将收到的实际产品，禁止使用绘图或插画。
* [ ] **分辨率**: 最长边至少 1000 像素，确保放大功能 (Zoom function) 可用。
* [ ] **禁止边框/水印**: 禁止出现任何边框、水印、文字或装饰元素。
* [ ] **禁止非白背景**: 主图禁止使用彩色背景或生活场景图。
* [ ] **禁止图纸**: 禁止使用工程图纸或草图。
* [ ] **禁止无关配件**: 禁止展示不包含在销售包装内的配件。
* [ ] **禁止占位符**: 禁止使用 "No Image Available" 等占位文本。
* [ ] **禁止促销文字**: 严禁包含 "SALE"、"Free Shipping" 等促销语。
* [ ] **禁止多色展示**: 同一主图位置禁止展示同一产品的多种颜色（变体应分开展示）。

### 1.2 标题合规 (Title Compliance)
* [ ] **首字母大写**: 每个单词首字母大写 (Title Case)。
* [ ] **虚词小写**: 连词 (and, or, for)、冠词 (the, a, an)、介词 (in, on, over, with) 必须小写。
* [ ] **数字格式**: 使用阿拉伯数字 (如 "2") 而非单词 (如 "two")。
* [ ] **捆绑说明**: 若为套装，必须明确数量 (如 "10-Pack")。
* [ ] **长度限制**: 字符数必须控制在 200 个字符以内。
* [ ] **字符规范**: 仅使用标准文本，禁止特殊符号 (如 ©, ™, ☆)。
* [ ] **禁止价格**: 标题中严禁包含价格或运费信息。
* [ ] **禁止全大写**: 禁止使用 ALL CAPS 格式。
* [ ] **禁止卖家信息**: 严禁包含卖家名称、电话或公司信息。
* [ ] **禁止主观词**: 严禁使用 "Hot Item", "Best Seller" 等主观营销词。

### 1.3 品牌与制造商 (Brand & Manufacturer)
* [ ] **品牌定义**: 必须填写用于区分产品的独特名称或商标。
* [ ] **制造商定义**: 必须填写实际制造该产品的企业名称。
* [ ] **自有品牌规则**: 除非产品为自有品牌 (Private Label)，否则禁止将卖家名称填入"品牌"或"制造商"字段。

### 1.4 五点描述 (Bullet Points)
* [ ] **核心功能**: 必须突出前 5 大功能或属性 (尺寸、年龄、原产国、保修)。
* [ ] **首字母大写**: 每个 Bullet Point 的首字母必须大写。
* [ ] **数字格式**: 使用阿拉伯数字。
* [ ] **单位拼写**: 完整拼写测量单位 (如 "inches" 而非 "in")。
* [ ] **分隔符**: 同一点内的短语使用分号 (;) 分隔。
* [ ] **句式规范**: 使用片段短语，末尾不加标点符号 (句号/感叹号)。
* [ ] **符号限制**: 开头禁止使用连字符、特殊符号。
* [ ] **具体化**: 描述必须具体，禁止模糊陈述。
* [ ] **禁止公司信息**: 严禁包含公司特定信息。
* [ ] **禁止促销信息**: 严禁包含定价、促销或运输信息。

### 1.5 产品描述 (Product Description)
* [ ] **功能描述**: 必须涵盖主要功能 (尺寸、样式、用途)。
* [ ] **参数准确**: 包含准确的尺寸、保养说明和保修信息。
* [ ] **语法规范**: 使用正确的语法、标点符号和完整句子。
* [ ] **禁止联系方式**: 严禁包含卖家邮箱、网站网址。
* [ ] **禁止公司详情**: 严禁包含公司特定介绍。
* [ ] **禁止交叉推广**: 严禁提及销售的其他产品详情。
* [ ] **禁止促销语言**: 严禁 "Sale", "Free Shipping" 等词汇。

### 1.6 其他通用合规 (General)
* [ ] **无货处理**: 无库存产品必须下架，或明确标注预计到货时间 (Restock Date)。
* [ ] **预售标注**: 预售产品必须在详情页写明发货时间。
* [ ] **链接检查**: 确保描述中无死链或 404 错误。
* [ ] **禁止造假插件**: **[高危红线]** 严禁使用任何制造虚假销量、虚假评论、虚假倒计时的插件或工具。

## 2. 账号身份验证材料清单 (Account Verification)

### 2.1 核心原则 (Core Principles)
* **真实性 (Authenticity)**: 必须为原始、未经任何 PS/篡改的文件。
* **清晰度 (Clarity)**: 彩色扫描或高清拍照，四角完整，文字清晰可读。
* **格式 (Format)**: 仅接受 PDF, PNG, JPEG, GIF。**严禁屏幕截图**。
* **一致性 (Consistency)**: 文件上的姓名/地址必须与 Seller Central 后台完全一致。

### 2.2 地址验证材料 (Utility Bills for 2nd Review)
提供以下任意一种公共事业账单：
* [ ] **管道燃气/天然气账单**
* [ ] **电力账单**
* [ ] **自来水账单**
* [ ] **固网电话/互联网宽带账单**

**要求**:
* 签发日期在过去 **90天** 内。
* 清晰显示姓名和注册地址。

### 2.3 视频验证材料 (Video Verification)
视频通话期间需展示原件：
* [ ] **身份证明**: 政府签发的带照片 ID (护照/驾照/身份证)。必须在有效期内，包含全名、生日、证件号、签名、签发国。非英文需公证翻译。
* [ ] **营业执照**: 注册时使用的企业营业执照原件。
* [ ] **银行对账单**: 银行或信用卡对账单 (180天内)。
* [ ] **供应链发票**: (如适用) 包含买卖双方详情、ASIN、数量的真实采购发票。

## 3. 封号申诉逻辑框架 (Appeal Logic Framework)

当面临账号停用或 Listing 下架时，必须遵循以下 **POA (Plan of Action)** 逻辑结构：

### 3.1 根本原因分析 (Root Cause)
> **逻辑**: 承认错误 -> 调查过程 -> 定位缺陷
* **责任确认**: 明确承认违规事实，不推卸责任。
* **内部调查**: 描述对违规事件的调查路径 (谁、什么时候、发现了什么)。
* **根源定位**: 指出导致违规的具体流程缺失或认知偏差 (例如: "员工未接受最新的 Listing 政策培训" 或 "缺乏上架前的多重审核机制")。

### 3.2 即时补救措施 (Immediate Remediation)
> **逻辑**: 止损动作 -> 证据留存
* **违规处理**: 说明已采取的动作 (如下架 ASIN、删除违规图片、退款给受影响买家)。
* **证据提供**: 附上后台操作截图、Listing 状态截图或买家沟通记录作为已执行的证据。

### 3.3 长期预防措施 (Preventative Measures)
> **逻辑**: 系统性整改 -> 培训 -> 监控 -> 承诺
* **流程重造**: 建立新的 SOP (例如: "引入 Listing 上架前的合规专员复审环节")。
* **团队培训**: 制定定期的亚马逊政策培训计划 (附上培训材料大纲)。
* **供应链管理**: 建立更严格的供应商审核与采购单据归档制度。
* **监控体系**: 设立每日/每周的账户健康巡检机制。
* **合规承诺**: 明确承诺未来将严格遵守平台政策。
