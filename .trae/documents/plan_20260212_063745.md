## 创建FastAPI主入口点

### 任务目标
在 `python_backend` 目录下创建 `main.py` 文件，设置 FastAPI 服务器来暴露 `report_engine_only` 逻辑给前端。

### 实现步骤

1. **创建 main.py 文件**
   - 使用用户提供的完整代码
   - 确保文件位于 `python_backend` 目录下

2. **代码结构**
   - 导入必要的库（uvicorn, FastAPI, CORSMiddleware, Pydantic）
   - 导入核心逻辑函数（generate_focus_topic, analyze_with_llm, generate_ceo_report）
   - 设置 CORS 中间件
   - 定义请求模型（BrainstormRequest, AnalyzeRequest）
   - 实现 API 端点（health_check, brainstorm_endpoint, analyze_endpoint）

3. **验证导入**
   - 确保 `report_engine_only.py` 在同一目录
   - 确保函数名称和参数与 `report_engine_only.py` 中的定义匹配

4. **测试启动**
   - 确保服务器能够在端口 8000 启动

### 预期结果
- FastAPI 服务器能够成功启动
- `/api/brainstorm` 端点能够生成具体的跨境电商主题
- `/api/analyze` 端点能够执行分析并生成报告
- 前端能够通过 API 与后端通信
