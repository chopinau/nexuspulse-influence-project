# Implementation Plan: NexusPulse OS Overhaul

## 1. Design System & Layout (The Shell)
- **Create `components/AppShell.tsx`**: A client-side wrapper component containing the Sidebar and Main Content area.
- **Create `components/Sidebar.tsx`**: The fixed left navigation with links to Dashboard, Archives, and Settings.
- **Update `app/layout.tsx`**: Wrap the entire application with `AppShell`.
- **Install Dependencies**: `npm install lucide-react sonner clsx tailwind-merge` (ensure these are present).

## 2. Refactor Dashboard (The Command Center)
- **Move Logic**: Move the complex dashboard logic from `app/page.tsx` to `app/dashboard/page.tsx`.
- **Redirect**: Update `app/page.tsx` to redirect to `/dashboard`.
- **Component Extraction**: Extract the Search Bar and Main Grid into reusable components in `components/dashboard/` if needed, or keep them in the page for now but ensure they fit the new layout.
- **Notifications**: Integrate `sonner` toaster in the layout and use it for feedback.

## 3. Implement "Intel Archives" Page
- **Create `app/archives/page.tsx`**: A server component (or client with effect) to fetch reports.
- **Backend API**: Create `app/api/reports/route.ts` to handle `GET` requests for fetching reports from Supabase.
- **UI**: Use a clean table design (using Tailwind) to display Date, Topic, Mode, Risk Score, and Verdict.
- **Details View**: Implement a simple expand/modal mechanism to view report details.

## 4. Implement "System Settings" Page
- **Create `app/settings/page.tsx`**: A client component for configuration.
- **Sections**:
  - **Notifications**: Form for Feishu/WeChat webhooks (save to LocalStorage).
  - **API Keys**: Form for Tavily/DeepSeek keys (save to LocalStorage).
  - **Expert Persona**: Static display of available skills (hardcoded list matching backend).
- **Styling**: Use the "IronCard" glassmorphism style for these forms.

## 5. Route & Component Cleanup
- **Shared UI**: Create `components/ui/GlassCard.tsx` (standardizing the "IronCard") and `components/ui/Button.tsx`.
- **Navigation**: Ensure active state highlighting in Sidebar.
- **Verification**: Verify all routes work and the layout is consistent.

**Aesthetic**: Adhere to the `bg-slate-950`, `text-slate-200`, Cyan/Rose accents, and Glassmorphism guidelines.
