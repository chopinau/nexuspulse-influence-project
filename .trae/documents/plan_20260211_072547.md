# Fix Search Logic for Complex Report Generation

## Problem Analysis
The current system fails to properly handle complex search terms with multiple components, resulting in reports that don't focus on the requested combination: "新兴品牌TWS Earbuds 在 Outdoor sport 市场中如何做Tiktok marketing" (Emerging brand TWS Earbuds how to do TikTok marketing in the Outdoor sport market).

## Root Causes
1. **Search Query Construction**: The query is built as `{category} {query}` but doesn't incorporate additional components like "Tiktok viral", "Brand incubation", "Outdoor", "sport"
2. **Intent Analysis Limitation**: Only categorizes input into 4 types, not handling complex multi-component search terms
3. **Prompt Assembly**: Doesn't properly incorporate all search components into the system prompt
4. **Topic Extraction**: No logic to extract and prioritize key components from user input
5. **Report Generation**: LLM generates general reports instead of focusing on the specific combination

## Solution

### 1. Enhance Search Query Construction
- **Modify `collect_intelligence` function** in `report_engine_only.py` to:
  - Extract key components from complex search terms
  - Construct a comprehensive search query that includes all relevant components
  - Add specific search terms for each component (e.g., "TWS Earbuds TikTok marketing outdoor sport brand incubation")

### 2. Improve Intent Analysis
- **Update `analyze_user_intent` function** in `report_engine_only.py` to:
  - Handle complex multi-component search terms
  - Extract product, marketing channel, strategy, and context components
  - Return a structured intent analysis with all extracted components

### 3. Refine Prompt Assembly
- **Enhance `assemble_system_prompt` function** in `prompts.py` to:
  - Incorporate all extracted search components into the system prompt
  - Add specific instructions for the LLM to focus on the combination of topics
  - Include mandatory sections that address each component of the search

### 4. Add Topic Extraction Logic
- **Add new function `extract_search_components`** in `report_engine_only.py` to:
  - Parse complex search terms with multiple components
  - Identify key components: Product, Marketing Channel, Strategy, Context
  - Prioritize components based on relevance

### 5. Focus Report Generation
- **Update `analyze_with_llm` function** in `report_engine_only.py` to:
  - Pass all extracted components to the LLM
  - Include specific instructions to generate reports that address the exact combination
  - Add mandatory sections for each component of the search
  - Ensure the report title and content reflect the specific combination

## Expected Outcome
After these changes, when users test search terms like "TWS Earbuds + Tiktok viral + Brand incubation + Outdoor + sport", the system will generate reports that specifically focus on "新兴品牌TWS Earbuds 在 Outdoor sport 市场中如何做Tiktok marketing" (Emerging brand TWS Earbuds how to do TikTok marketing in the Outdoor sport market), addressing all components of the search query in a cohesive strategy.
