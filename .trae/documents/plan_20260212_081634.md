# 集成新的Python后端分析引擎代码

## 问题分析

用户提供了一个新的Python后端分析引擎代码，包含以下主要函数：

1. `generate_focus_topic`: 智能联想，生成焦点话题
2. `get_market_intel`: 搜集情报，使用Tavily搜索市场数据
3. `analyze_with_llm`: 残酷分析，生成分析结果和Mermaid代码
4. `generate_ceo_report`: 生成战报，将分析结果转换为Markdown格式

现有代码结构：
- `report_engine_only.py`: 包含核心分析逻辑
- `main.py`: FastAPI主文件，提供API端点

## 集成方案

### 1. 评估代码结构

对比分析显示，用户提供的代码与现有代码结构相似，但有以下差异：
- `generate_focus_topic`函数：用户代码更简单，现有代码更详细
- `get_market_intel`函数：搜索深度和结果处理不同
- `analyze_with_llm`函数：提示词和JSON结构不同
- `generate_ceo_report`函数：报告格式不同

### 2. 集成策略

考虑到现有代码已经经过测试并运行正常，我建议采用**选择性集成**策略：

1. **保留现有代码结构**：确保API端点兼容性
2. **更新关键功能**：集成用户代码中的改进
3. **确保数据结构兼容**：确保返回的数据结构与前端期望一致

### 3. 具体修改计划

#### 3.1 更新 `report_engine_only.py`

1. **保留现有函数结构**：保持`generate_focus_topic`、`analyze_with_llm`、`generate_ceo_report`函数签名不变

2. **更新 `get_market_intel` 函数**：
   - 集成用户代码中的搜索逻辑
   - 确保返回的数据结构与现有代码一致

3. **优化 `analyze_with_llm` 函数**：
   - 保留现有的错误处理和日志记录
   - 集成用户代码中的分析逻辑
   - 确保返回的数据结构包含所有必要字段

4. **更新 `generate_ceo_report` 函数**：
   - 保留现有的报告格式
   - 集成用户代码中的改进

#### 3.2 验证 `main.py`

1. **确认API端点兼容性**：确保现有的`/api/brainstorm`和`/api/analyze`端点仍然有效

2. **验证数据结构**：确保API返回的数据结构与前端期望一致

3. **测试错误处理**：确保异常处理机制正常工作

### 4. 测试计划

1. **单元测试**：测试每个函数的功能
2. **集成测试**：测试API端点的功能
3. **端到端测试**：测试整个系统的功能

### 5. 预期结果

集成后，系统应该：
1. 保持现有的API端点兼容性
2. 提供更准确的市场分析
3. 生成更详细的分析报告
4. 提供更美观的Mermaid图表

### 6. 技术要点

- **代码兼容性**：确保修改后的代码与现有代码兼容
- **数据结构一致性**：确保返回的数据结构与前端期望一致
